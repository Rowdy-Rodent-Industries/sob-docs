# Map Marker Cheat Sheet

*Written by CC-3255/01 “Mokka”*

## Document Information

- This document serves as a quick reference sheet for marking various locations on the map during pre-Op planning.
- This document contains both formatting guidelines and naming resources (“alphabets”) as well as a glossary to provide definitions for the various locations that can be marked.

## General Guidelines

- Try using the colour of the element that you are marking things for, even if it takes more time. It makes the map more readable in the long run.
- It’s usually a good idea to name objectives alphabetically
  - Not necessarily always starting at ‘A’, but always continuing the alphabet from any given starting letter
- Locations need not be named alphabetically, especially since there’s usually one or two of them, at most
- There are different “alphabets” for choosing Marker Names, Platoon Leaders are strongly requested to pick & choose one of the Alphabets to name their Platoon’s specific markers (eg. Alpha Plt takes Creature Alphabet, Zulu Plt takes Wood Alphabet)

## Marker Name Formats

Snippets encased by square brackets (`[`, `]`) are to be replaced with the relevant element.

| Type | Format | Example |
| --- | --- | --- |
| Objectives | OBJ [Obj Name] | OBJ Aurek, OBJ Dorn |
| Landing Zone | LZ [Marker Name] | LZ Oak, LZ Iron |
| Drop Zone | DZ [Marker Name] | DZ Spruce, DZ Silver |
| Rally Point | RP [Marker Name]\|[Nr] | RP Pine, RP 1, RP 1-1 |
| Waypoint | WP [Marker Name] [Nr] | WP Birch, WP 1, WP 1-1 |
| Overwatch | OW [Marker Name] [Nr] | OW Ruby, OW 1, OW 1-1 |

## Glossary

A brief description of what the various types of markers are to be used for.

| Type | Explanation |
| --- | --- |
| Objectives | The central parts of operations, the actual locations that the various platoon will operate at |
| Landing Zone | Any location where a friendly aircraft is expected to land in order to insert or evacuate troops |
| Drop Zone | Any location where friendly units are expected to land during an airborne insert |
| Rally Point | Any location where friendly elements are expected to regroup before/after certain stages of the plan |
| Waypoint | Any location that a friendly element is expected to pass while navigating from one position to another; waypoints are used by command personnel to track the progress of elements on their route and as fallback points |
| Overwatch | Any location that is designated for friendly forces to be used to gather information about an objective ahead of the assault |
| Attack Position | Any location that is designated for friendly forces to be used to stage an assault, eg. by forming a base line or a bounding manoeuvre |
| Forward Operating Base | Forward Operating Bases are major installations used to support friendly forces by serving them as a supply/respawn location |
| Casualty Collection Point | A Casualty Collection Point is a predesignated or improvised location that is used to treat mas-cas events and to alleviate friendly forces of the burden of casualties |
| Combat Outpost | A combat outpost is a small installation that is constructed to support friendly forces during a combat operation, eg. by providing fortified fighting positions and small amounts of supplies |
| Fire Support Target | A Fire Support Target is a predesignated location of interest that is to be assaulted by a Fire Support element (CAS, Artillery, …) during the course of a mission |
