# SOB Documentation

GitHub Pages documentation site. In GitHub Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)`.

Edit the `.md` files to update content. `_layouts/default.html` contains navigation, and `assets/style.css` controls the white/black theme.

## Training Refreshers

Ten training-reference Markdown pages are included, with source PDFs in `assets/training/` and page images for complex tables/diagrams. All ten are linked in the sidebar and homepage and indexed by site search.
