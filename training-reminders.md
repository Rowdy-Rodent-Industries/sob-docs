- Recon Training Notes

### Navigation

Triangulation- Use different reference points to get current position. To obtain a “retrograde”

bearing to the target take your bearing and add/subtract 180 to get the reverse. Draw a line from

both the reference point and the “retrograde” bearing to get a rough idea of where you are. If you

have two reference points and those lines cross, you have found your position

Land Nav- Use a route that subdivides the distance into several smaller parts using waypoints to

mark various stages.

Stealth- Key for recon units

- MSE Modes

Payload Type The payload type is what kind of reaction the MSE will have should it detonate.

SAFE - The MSE will not explode.

RANDOM - The MSE will randomly select between EMP or EXPLOSIVE.

EMP - The MSE will release an EMP explosion.

EXPLOSIVE - The MSE will release a normal explosion.

Operation Type The operation type is to determine what kind of function the MSE will serve.

SURVEILLANCE - The MSE will be used for recon, using only its driving functionalities.

COURIER - The MSE will be used to deliver small objects, the user will be able to insert small items into the MSE

DEMINING - The MSE will be used to deliver an explosive payload, the user will be able to detonate the MSE on command.

Data Protection Mode The MSE has a built in Data Protection protocol to avoid information falling into the wrong hands.

ON HIT - If the MSE takes any amount of damage, the MSE will detonate.

ON IMMOBILIZED - If the MSE becomes immobilised, the MSE will detonate.
