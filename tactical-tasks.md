# SOB Tactical Tasks

Tactical Tasks are clearly defined and measurable activities accomplished by the Platoon. Commanders are advised to always use the correct terms in this context!

Tasks are categorised into three types:

- Offensive Tasks
- Defensive Tasks
- Tactical Shaping Tasks

## Offensive Tasks

| Task | Description |
| --- | --- |
| Ambush | An Attack by Fire from concealed positions on a moving or temporarily halted enemy. |
| Attack by Fire | An offensive task in which a Commander uses direct fire, supported by indirect fires, to engage an enemy force without closing with him to destroy, suppress, fix, or deceive that enemy. |
| Breach | An offensive task in which a Platoon/Squad employs all available means to break through (or establish a passage through) an enemy defence, obstacle, minefield, or fortification. |
| Clear | An offensive task that requires the Commander to remove all enemy forces and eliminate organised resistance within an assigned area. |
| Destroy | An offensive task that physically renders an enemy force combat-ineffective until it is reconstituted. Alternatively, to damage an enemy installation or combat system so badly that it cannot perform any function or be restored to a usable condition without being entirely rebuilt. |
| Exfiltrate | An offensive task where a Commander removes Individuals or a Platoon/Squad from areas under enemy control by stealth, deception, surprise or clandestine means. |
| Follow and Support | An offensive task in which a committed force follows and supports a lead force conducting an offensive task. The following force may be expected to continue the mission if the lead force is fixed, attrited, or unable to continue. |
| Seize | An offensive task that involves taking possession of a designated area using overwhelming force. |
| Support by Fire | An offensive task in which a manoeuvre force moves to a position where it can engage the enemy by direct fire in support of another manoeuvring force. |

## Defensive Tasks

| Task | Description |
| --- | --- |
| Occupy | A defensive task that involves a Commander moving a friendly force into an area so that it can control that area and keeps it free of enemy occupation or use. |
| Protect | A defensive task that involves a Platoon/Squad providing security for a mobile force/individual |
| Secure | A defensive task that involves preventing a unit, facility, or geographical location from being damaged or destroyed as a result of enemy action. |

## Tactical Shaping Tasks

| Task | Description |
| --- | --- |
| Approach | A tactical shaping task that involves a Commander moving their troops to a designated position with minimal contact. |
| Disengage | A tactical shaping task where a Commander has a Platoon/Squad break contact with the enemy to allow the conduct of another mission or to avoid decisive engagement. |
| Fire and Maneuver | A tactical shaping task that involves a Platoon/Squad splitting in two elements, where one element moves while the other is stationary and engages/suppresses the enemy force. |
| Reconnaissance | A tactical shaping task that involves a Platoon/Squad observing and gathering information about an area, including details about the position and strength of enemy forces and points of interest. |
| Recon in Force | An aggressive tactical shaping task that involves a Commander using their force to conduct non-committal attacks on enemy positions in order to establish their strength and capabilities. |
| Reorganise | A tactical shaping task that involves a Commander gathering all the forces under their command in one position to assess their combat-effectiveness and to prepare them for the next parts of the mission. |
