# Zeus Asset Limitations

*Written by CC-7130/80 “Sparrow”*

## Document Information

- This document contains a list of Asset Limitations/Bans for our Zeus players and Mission Makers.
- The document will be updated irregularly to reflect additions, changes and removals as necessary. We will try to keep you notified as and when changes occur.

## General Guidelines

- Use common sense when placing units and compositions, keep in mind the projected number of Infantry and Warden that will tackle a given problem.
- A general object limit of 3000 objects are allowed on mission files.

## Asset Limitations

| Asset Name | Limitation |
| --- | --- |
| AAT-S (Black AAT) | Two per Platoon at a time (so max would be 4/Op at one time) |
| HMP-S (Black HMP) | Only one active at any given time |
| MTT | Only one actively deploying units at any given time/max 1 per platoon - Multiple MTTs are approved for Convoy use |
| Droid Dispensers | Only up to six active at any given time for the whole company |
| B2 Droid Dispensers | Two active at any given time per platoon |
| Jaro’tsad Scorpion | Two per Platoon (so max. 4/Op) |
| Jaro’tsad Scorpion (Gridlock) | Two per Platoon (so max. 4/Op) |
| 21st CIS Assets | Banned from use |
| Hellfire Smasher | Max two per platoon in an OP (So max. 4/Op) |
| Acid + Regular Smasher | Max two per platoon in an OP (So max. 4/Op) |
| Goliath | Max one per Platoon if infantry numbers are fair (So max. 2/Op) |
| HailFire SAM | Banned from use |
| Keldabe-Class Cruiser | Max one per operation |
| FTL Ship of any kind | Non-combat no limitation/Combat ships are limited to 1 per AO |
| AT-AT/AT-ST (Warmantle) | Banned (note: They are showcasing new WIP versions that we can test in the future) |
| SOB Assets | Banned from usage against players; use 3as or LS as enemy clones |
| Vulture-S | Limited to two per wave |
| Rocket Base AA (Lances, whistlebird, etc.) | 2 per AO (Ex. AO Acklay or AO Bocatt) |

## Module Limitations

| Module Name | Limitation |
| --- | --- |
| AoE Fire Supports | Careful: large areas can cause massive lag spikes |
| Minefields | Large areas can cause massive lag and even brick the server! Prefer using multiple, smaller fields to cover an area |
| Nuke Module | Only use for SFX purposes, inform Command ahead of time |
| Meteor Module | Banned, breaks the server |
| Any other “World-ending” Module | Banned, potential to break the server |
